# Answer codes of the FluSurvey questionnaires

Labels for the coded answers, by question.
[`read_data`](https://sbfnk.github.io/flusurvey/reference/read_data.md)
uses them to turn coded answers into factors.

## Usage

``` r
options
```

## Format

A list with one named character vector per question that maps answer
codes to labels

`R/define_questions.r`
