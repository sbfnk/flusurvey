# Calculate incidence from flusurvey data

This calculates incidence according to a given column in the supplied
data.

## Usage

``` r
get_incidence(
  data,
  incidence.columns = "ili",
  aggregation = c("week", "day", "month", "year"),
  denominator = c("active.members", "reports"),
  min.N = 1,
  by = NULL,
  exclude = NULL,
  start.date = c("earliest", "last"),
  missing.start = c("first.report", "missing"),
  inverted.dates = c("keep", "clear", "reset.end"),
  precedence = c("dates", "continuation", "report.date"),
  unresolved = c("fill", "missing"),
  chronic = c("none", "duration"),
  chronic.days = NULL
)
```

## Arguments

- data:

  a data table, usually generated by
  [`merge_data`](https://sbfnk.github.io/flusurvey/reference/merge_data.md)

- incidence.columns:

  one or more columns which specificy incidence; default: "ili"

- aggregation:

  the timescale of aggregation, by default "week"

- denominator:

  what to use as denominator, active members or all reports in a week

- min.N:

  the minimum denominator, by default 1

- by:

  one or more variables by which to group

- exclude:

  bouts to leave out of the incidence: any of "unknown.onset" (no
  reported start date, which needs `missing.start = "missing"`),
  "unknown.end" (no reported end date, which needs
  `unresolved = "missing"`) and "ongoing.at.entry" (see below); by
  default none

- start.date, missing.start, inverted.dates, precedence, unresolved:

  how bouts and their dates are set, see
  [`bouts_of_illness`](https://sbfnk.github.io/flusurvey/reference/bouts_of_illness.md);
  `start.date` defaults to "earliest" in both

- chronic, chronic.days:

  chronic report rule passed to
  [`bouts_of_illness`](https://sbfnk.github.io/flusurvey/reference/bouts_of_illness.md);
  all reports remain in the denominator

## Value

a data.table with the incidence

## Details

A bout is ongoing at entry when its start is before the participant's
first report. `exclude = "ongoing.at.entry"` uses the
`illness.ongoing.at.entry` column from
[`merge_data`](https://sbfnk.github.io/flusurvey/reference/merge_data.md),
which compares each reported start date with the first report, taken
before `remove.first` drops it; a bout has the flag if any of its
reports does. Without that column in the data, a bout counts as ongoing
at entry when its selected start date (see `start.date`, `missing.start`
and `inverted.dates`) is before its `min.date`. The flag uses the dates
as reported, but the `min.date` comparison uses the start date chosen
for the bout.

By default bouts ongoing at entry are included. For incidence, a start
before the first report is assigned to the first retained report.
Including or excluding these bouts can materially change incidence in
the survey data. An analysis should state whether they were included.
