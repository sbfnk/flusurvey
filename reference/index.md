# Package index

## Read and clean

- [`read_data()`](https://sbfnk.github.io/flusurvey/reference/read_data.md)
  : This reads in flusurvey data for a given year
- [`extract_data()`](https://sbfnk.github.io/flusurvey/reference/extract_data.md)
  : Extract flusurvey data
- [`merge_data()`](https://sbfnk.github.io/flusurvey/reference/merge_data.md)
  : Clean and merge flusurvey data tables

## Case definitions, incidence and episodes

- [`aggregate_symptoms()`](https://sbfnk.github.io/flusurvey/reference/aggregate_symptoms.md)
  : Aggregate symptoms in symptom table to work out ILI etc.
- [`get_incidence()`](https://sbfnk.github.io/flusurvey/reference/get_incidence.md)
  : Calculate incidence from flusurvey data
- [`bouts_of_illness()`](https://sbfnk.github.io/flusurvey/reference/bouts_of_illness.md)
  : Extract bouts of illness from a flusurvey data table
- [`bout_evidence()`](https://sbfnk.github.io/flusurvey/reference/bout_evidence.md)
  : Evidence behind the bouts of illness
- [`contact_illness()`](https://sbfnk.github.io/flusurvey/reference/contact_illness.md)
  : Illness status of contact reports

## Bundled data

- [`questions`](https://sbfnk.github.io/flusurvey/reference/questions.md)
  : Question codes of the FluSurvey questionnaires
- [`options`](https://sbfnk.github.io/flusurvey/reference/options.md) :
  Answer codes of the FluSurvey questionnaires
- [`regions`](https://sbfnk.github.io/flusurvey/reference/regions.md) :
  Regions of UK postcode districts
- [`urban_rural`](https://sbfnk.github.io/flusurvey/reference/urban_rural.md)
  : Country and settlement type of UK postcode districts
- [`simulated_data`](https://sbfnk.github.io/flusurvey/reference/simulated_data.md)
  : Simulated FluSurvey data
